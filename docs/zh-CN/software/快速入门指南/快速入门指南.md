# Preface<a name="ZH-CN_TOPIC_0000001808700609"></a>

**Overview<a name="section4537382116410"></a>**

This document is written for developers who use the product for the first time. It aims to help developers quickly grasp the overall architecture of the documentation and guide them step by step through in-depth development. It also helps different developers quickly find the documents they need.

>![](public_sys-resources/icon-notice.gif) **Note:** 
>-   Chapter 1 is the directory of the version package documents, describing the overall structure of the documentation.
>-   Chapter 2 is the environment setup part, including chip evaluation, development environment setup, and Demo board usage.
>-   Chapter 3 is the basic function development chapter, containing documents for various parts that customers need for development.
>-   Chapter 4 is the optimization chapter, mainly helping customers optimize image, memory, bandwidth, and other aspects after basic development.
>-   Chapter 5 is feature development, helping customers quickly find all documents related to a feature when developing a single feature.
>-   Chapter 6 is test reports, including power consumption and hardware test reports for customer reference.

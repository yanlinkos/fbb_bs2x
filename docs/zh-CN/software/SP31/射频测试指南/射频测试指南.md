## Flowchart<a name="ZH-CN_TOPIC_0000002219309477"></a>

Both the remote control side and the dongle side require transmit power calibration and spectrum verification of whether the -10dB bandwidth is greater than 500MHz. This test does not require interaction between the remote control and the dongle. After power-on calibration is complete, the calibration verification can be performed separately. During this process, ensure that the SLP is not powered off when Bluetooth is disconnected. The specific flow is shown in [Figure 1](#fig2338518690).

## Spectrum Analyzer Settings<a name="ZH-CN_TOPIC_0000002183823696"></a>

The frequency range of the spectrum analyzer must cover at least 6\~8.5GHz. Parameter settings (refer to the specific spectrum analyzer button labels for setting items):

Freq=7.9872GHz

Span=1GHz

RBW=1MHz

VBW=3MHz

Sweep time=2s

Sweep points=2001

Trace mode=max hold

Detector=RMS

Offset=Loss of the Spectrum Analyzer and Cable

**Figure 1**  Typical Spectrum Analyzer Settings (For Reference Only)<a name="fig1967410136436"></a>  
![](figures/频谱仪设置典型参数（仅供参考）.png "Typical Spectrum Analyzer Settings (For Reference Only)")

Example of the AT command operation flow for continuous TX:

1.  Load the SLP firmware: AT+SLPPOWERON.
2.  Set RF parameters: AT+SLPSETRFSWPARAM=0,3,2,0,0,0,0,0 (example; the actual values must match the board design. For details, see the "Sample User Guide")
3.  Enable continuous TX: AT+SLPSTARTRANGING=1,1,1,0,0,20,1,0xA54A,0x254A
4.  Disable continuous TX: AT+SLPSTARTRANGING=1,1,1,0,0,20,2,0xA54A,0x254A

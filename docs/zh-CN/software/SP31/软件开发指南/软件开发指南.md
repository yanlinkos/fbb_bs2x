# Error Codes<a name="ZH-CN_TOPIC_0000002219226721"></a>

When the SLP interface call is completed or an exception is encountered during the SLP business execution, an error code will be reported. Users can troubleshoot problems through the error codes. Error codes are divided into the following three levels:

INFO: indicates that the interface was executed successfully;

WARNING: a reminder-type error; the typical scenario is repeated state switching; this error does not affect normal functions and can be ignored or used to troubleshoot redundant code flows;

ERROR: a serious error that may cause the business startup to fail; the cause needs to be investigated to avoid such errors.

# Development Process<a name="ZH-CN_TOPIC_0000002219226717"></a>

Taking the Air Mouse scenario as an example, only the development description involving the SLP interface is involved. For specific programming examples, refer to application/samples/products/air_mouse.

RCU side:

1. Call SlpSetUartBuffer to set the UART buffer.
2. Call SlpRegisterCommandCallbacks to register the SLP command callback functions.
3. Call SlpSetLocalAttCommand to set the local device attributes.
4. Call SlpRecvPayload to register the SLP payload reception function.
5. Call SlpRegisterSendPayloadCallback to register the SLP payload sending function.
6. Call SlpRegisterReportCallbacks to register the result report callbacks.
7. Call SlpSetTransformParam to set the coordinate system transformation parameters.
8. After SLE connection pairing succeeds, call SlpPowerOnCommand to load SLP.
9. Call SlpStartRangingCommand to start SLP ranging.
10. During the interaction process, call SlpRecvPayload to receive the payload sent by the peer.
11. If SLP needs to sleep, call SlpSleepCommand. If wake-up is needed, call SlpStartRangingCommand again to start SLP ranging.
12. If SLE is disconnected, call SlpPowerOffCommand. The local SLP is powered off, and the peer slp enters the low-power state.

Dongle side:

1. Call SlpSetUartBuffer to set the UART buffer.
2. Call SlpRegisterCommandCallbacks to register the SLP command callback functions.
3. Call SlpSetLocalAttCommand to set the local device attributes.
4. Call SlpRecvPayload to register the SLP payload reception function.
5. Call SlpRegisterSendPayloadCallback to register the SLP payload sending function.
6. Call SlpRegisterCommandCallbacks to register the command callback functions.
7. Call SlpRegisterReportCallbacks to register the result report callback functions.
8. Call SlpSetInstParam to set the installation parameters.
9. After SLE connection pairing succeeds, call SlpPowerOnCommand to load SLP.
10. The SlpReportCursorCallback interface continuously reports cursor results.
11. The SlpReportRangingCallback interface continuously reports ranging and angle measurement value results.
12. If SLE is disconnected, call SlpPowerOffCommand to power off SLP.
